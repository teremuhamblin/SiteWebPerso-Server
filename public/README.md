# Dossier public/

Contient les fichiers accessibles par l’interface web du serveur.

## Contenu
- index.html — page d’accueil de l’interface admin
- dashboard.html — tableau de bord
- logs.html — consultation des journaux
- backups.html — gestion des sauvegardes
- assets/ — images, icônes, logo
